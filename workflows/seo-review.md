# Workflow: SEO Architecture and Release Review

1. List route families and classify indexability.
2. Identify target queries/intents and the unique purpose of each landing page.
3. Compare rendering strategies and verify initial HTML for representative routes.
4. Specify URL/language rules, canonicals, hreflang, redirects, query parameters, and indexation controls.
5. Define title/description/heading/content patterns and editorial ownership.
6. Decide relevant structured data based on visible content and supported use cases.
7. Verify internal-link graph, sitemap generation, robots behavior, status codes, and noindex behavior.
8. Set accessibility/performance budgets and test mobile experience.
9. Define analytics/search monitoring and a post-release validation owner.
10. Record decisions and evidence in the SEO plan and ADRs.
