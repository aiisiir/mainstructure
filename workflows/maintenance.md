# Workflow: Maintenance and Continuous Improvement

1. Review incident reports, support issues, error trends, performance, costs, dependency advisories, and user outcomes.
2. Distinguish root causes from symptoms; write actionable follow-up work.
3. Prioritize using user impact, security/data risk, recurrence, cost, and deadline.
4. Update tests/runbooks/monitoring to prevent recurrence where feasible.
5. For recurring patterns, decide whether to improve the project, a profile, an adapter, or the framework core.
6. Record evidence and version framework changes.

Do not generalize from a single unusual project without checking broader applicability.
