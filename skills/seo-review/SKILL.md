# SEO Review Skill

Read `core/seo-and-discoverability.md` and `quality-gates/seo-gate.md`. Inventory route families and indexability, inspect actual initial HTML and HTTP behavior, check title/description/canonical/language/hreflang, robots/noindex, sitemap membership, redirects, internal links, structured data accuracy, mobile/accessibility, and performance. Review content intent and uniqueness, not metadata alone. Report blockers separately from improvements and cite test evidence. Do not promise rankings.
