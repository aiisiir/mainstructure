# Canonical Agent Skills

These task-specific instructions are the framework source of truth. They are intentionally separate from core policy: skills guide how to perform a task; `FRAMEWORK.md` and `core/` define what the engineering process requires.

| Skill | Use when |
|---|---|
| `requirements-analysis` | Turning a request into traceable, testable requirements |
| `architecture-review` | Comparing boundaries, risks, complexity and architecture options |
| `threat-modeling` | Reviewing a feature/system for security threats and controls |
| `test-strategy` | Mapping risks/requirements to verification |
| `seo-review` | Reviewing public web discoverability and technical SEO |
| `stack-selection` | Comparing technology candidates and recording evidence |
| `release-readiness` | Checking release gates and reporting evidence honestly |

Use the skill files as guidance for compatible AI coding tools. For clients that require a special folder or format, create and review an adapter for that client; do not assume an integration is installed or automatically synchronized.
