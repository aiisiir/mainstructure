# Release Readiness Skill

Verify applicable build/test/security/accessibility/performance/backup/rollback/monitoring gates. For SEO-critical web projects, test production URLs, initial content, statuses, canonical/language alternates, robots, sitemap, redirects, schema, and mobile/performance. Report each item as pass, fail, blocked, not applicable, or not run with evidence. Identify accountable risk acceptance for remaining issues. Never mark unrun checks as passed.
