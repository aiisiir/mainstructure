# Architecture Review Skill

Evaluate context/boundaries, responsibilities, data ownership, failure modes, consistency, trust boundaries, deployment, observability, migrations, operating cost, exit cost, and quality attributes. For public web projects, explicitly assess rendering/crawl strategy, URLs, localization, caching, canonicalization, and URL migration. Compare at least one viable alternative for material decisions. Return prioritized findings with evidence and an ADR-ready recommendation. Avoid cargo-cult patterns.
