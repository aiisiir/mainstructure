# Stack Selection Skill

1. Read project constraints, workload assumptions, profile, and success criteria.
2. Separate hard constraints from preferences.
3. Generate a bounded list of viable candidates, including reuse/buy options where reasonable.
4. Score only after agreeing criteria/weights; state evidence and confidence.
5. Consider total cost of ownership, security maintenance, skills, operations, SEO/rendering, interoperability, portability, and exit cost.
6. Recommend spikes for high-impact uncertain scores.
7. Produce a decision record with alternatives, trade-offs, risks, and review triggers.

The score supports a human decision; it is not an objective truth or a universal technology ranking.
