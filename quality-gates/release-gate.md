# Quality Gate: Release

- [ ] Required build/test/analysis checks pass or have explicit disposition.
- [ ] Critical user journeys and authorization are verified.
- [ ] No unresolved critical security/data-integrity blocker.
- [ ] Production configuration, secrets, migrations, and compatibility are reviewed.
- [ ] Backup/restore or rollback evidence exists proportionate to risk.
- [ ] Monitoring, owner, escalation and runbook are ready.
- [ ] Accessibility and performance requirements meet the agreed threshold.
- [ ] SEO gate passes for public/indexable web content, or an authorized exception names impact, owner, and expiry.
- [ ] Release decision and rollback trigger are explicit.
