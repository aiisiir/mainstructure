# Quality Gate: Implementation

- [ ] Acceptance criteria are met and linked to tests/evidence.
- [ ] Tests cover meaningful failure and permission-denied behavior.
- [ ] No unrelated or unexplained changes are included.
- [ ] Input validation, error handling, logging and secrets are reviewed.
- [ ] Data integrity, concurrency, transactions, and idempotency are addressed where relevant.
- [ ] Dependency and static-analysis output is reviewed.
- [ ] Accessibility/performance checks are run as applicable.
- [ ] SEO implications of routes, rendered content, metadata, links, and URL changes are reviewed when applicable.
- [ ] Documentation/ADR/profile/traceability is updated.
- [ ] Verification status is accurately reported.
