# Quality Gate: Operations

- [ ] Named service owner and support path.
- [ ] Deployment steps are repeatable and environment configuration is documented.
- [ ] Secrets/configuration are separated from source code.
- [ ] Logs/metrics/traces or equivalent signals are useful, accessible only to appropriate roles, and do not leak secrets.
- [ ] Alert thresholds have an action and an owner.
- [ ] Backup policy and recovery objectives (RPO/RTO) are defined where data loss/downtime matter.
- [ ] Restore/rollback is tested; evidence and limitations are documented.
- [ ] Dependency patching and deprecation responsibility is assigned.
- [ ] Runbook includes common failures, diagnosis, escalation, and mitigation.
- [ ] SEO/search visibility monitoring is owned for public sites.
